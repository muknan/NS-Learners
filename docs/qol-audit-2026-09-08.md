# QOL pass — 8 September 2026

Reviewed the routes, exam state and timers, session storage, scoring and results,
flashcards, shared controls, mobile CSS, error recovery, offline configuration and
test/build setup. The previous removal of result-summary dots is deployed and retained.

## Implemented

- Flashcard shuffling uses the remaining unseen cards before repeating a batch.
  A final partial batch is allowed; the cycle starts over once the pool is exhausted.
- Added a **To learn** filter excluding known cards, with a clear completed state
  and access to more cards when a batch is finished.
- Category filters wrap on small screens so they are discoverable without a hidden
  horizontal scrollbar. Cross-tab known-card updates preserve the current unknown batch.
- Results can show questions needing review, flagged questions or all answers.
  Correct answers retain correct styling in the expanded review; text-only cards no
  longer reserve a blank image placeholder.
- Results show completion time and recover the expired label from stored deadlines
  when reopened from history.
- Section breakdowns consistently say **Unanswered**, expose all score counts to
  assistive technology and no longer create a tiny unanswered segment for perfect scores.
- Shared summaries omit categories absent from the attempt and order topics by score.
- The answer reducer rejects another answer after instant feedback locks a question.
- Failed delay-setting writes preserve the previous selection and show a visible error.
- Removing the save-progress URL parameter preserves the framework's browser-history state.

Changes reuse existing controls, state and storage. No dependencies, backend services,
accounts, palette replacement or scoring-rule changes were added.

## Verification scope

Validation passed: 72 unit tests, all 53 browser tests in the final full run, lint,
the production build (including TypeScript checks), and diff whitespace checks.

Tests cover the remaining partial flashcard batch, unknown-only completion, answer
locking, score accessibility, review filters, historical expiry and setting-save failures,
alongside the existing complete exam, save/resume, offline and responsive checks.
Visual checks cover the new filters and review at narrow widths in light and dark themes.

This is a code and browser QA pass, not a new factual certification of every driving
rule. Physical iOS and dedicated screen-reader testing remain separate checks. Browser
storage still has no cloud backup; exact simultaneous flashcard writes in separate tabs
are not transactional. Broader study scheduling and analytics remain outside this pass.
